## Лабораторная 1 — Получение и предобработка текстовых данных

Задача: собрать корпус текстов из открытых источников (API соцсетей или веб-скрейпинг), выполнить предобработку и сохранить чистый набор данных.

1. Источник данных - Телеграмм каналы. В базовой версии клиента есть возможность экспортировать чат в разных форматах.
Было экспортировано 6 чатов в формате json, суммарно получилось более 10000 записей.
2. Все экспортированные файлы были собраны в один файл messages.json с помощью скрипта first_lab.py. 
Записи состоят из уникального id - название канала и его номер, raw - необработанный текст, author - автор записи
если в канале включены отображения авторов, date - дата записи, reactions - реакции под записью, preprocess_text
обработанный текст. Если сообщение содержит менее 3х слов, то данный текст не учитывается.
3. Перед записей файлов в messages.json была проведена предобработка, в ней удалены все url, затем все слова лемантизируются
с помощью pymorphy3 и удаляются все пробелы. Реализация функцией preprocess_text
